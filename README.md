 # Job_portal(MERN Stack + AI Interview)
Designed and developed a full-featured job portal using the MERN stack with AI-based interview simulation functionality.

•	Built responsive frontend using React.js with Tailwind CSS and dynamic routing

•	Developed secure backend with Node.js and Express.js, including authentication and role-based access (admin/recruiter/candidate)

•	Integrated MongoDB for managing user data, job listings, and applications

•	Added AI interview feature to simulate real interview questions and responses

•	Enabled resume upload, job filtering
